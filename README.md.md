# Rafaela Colussi — Cardápio digital

Site estático responsivo em HTML, CSS e JavaScript, preparado para publicação gratuita no GitHub Pages.

## Arquivos
- `index.html`: conteúdo e produtos
- `style.css`: identidade visual e responsividade
- `script.js`: botões de encomenda via WhatsApp
- `img/`: coloque aqui as fotos reais

## Como adicionar as fotos
Copie suas fotos para a pasta `img/` e renomeie-as exatamente para:
- `hero.jpg` — foto principal da capa
- `torta-limao-chocolate.jpg`
- `torta-limao-mirtilo.jpg`
- `cheesecake-mirtilo.jpg`
- `cheesecake-flocos-frutas-vermelhas.jpg`

Se suas fotos estiverem em PNG ou WEBP, altere a extensão correspondente no `index.html`. Os espaços reservados aparecem automaticamente enquanto as fotos não forem adicionadas.

## Antes de publicar
1. Confira os nomes, descrições e preços.
2. Teste os links do WhatsApp e Instagram.
3. Confira a visualização em celular.
4. O endereço residencial não aparece no site; a página informa que o local será combinado em particular.
5. A conservação/validade não foi informada e, por isso, não foi incluída.

## Publicar gratuitamente com GitHub Pages
1. Crie ou entre em uma conta em https://github.com/
2. Crie um repositório público, por exemplo `cardapio-rafaela-colussi`.
3. Envie `index.html`, `style.css`, `script.js` e a pasta `img/` para a raiz do repositório.
4. No repositório, acesse **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**, escolha `main` e `/ (root)` e salve.
6. Aguarde a publicação e abra o endereço exibido na seção Pages. Pode levar alguns minutos.

O código-fonte de um repositório público pode ser visto por qualquer pessoa. Não coloque informações privadas nele.
